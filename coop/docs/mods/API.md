# Mod API reference

> Generated by `2ship-coop-server --mod-docs <folder>` from the code. Do not edit by hand.

Getting started guide: [README.md](README.md). Item, actor and scene names: [IDS.md](IDS.md). DLL plugins: [PLUGINS.md](PLUGINS.md).

## Functions

In a script they are called `coop.<namespace>.<function>(...)`; in a plugin, `api.Call("<namespace>.<function>", { ... })` with the same arguments in a list. An argument with `?` can be omitted (or passed as `nil`). If one is wrong, the function raises an error that starts with its name (in Lua, with the file and line; `pcall` catches it).

Arguments that repeat:

- **player**: a connected player, by id (number) or nick.
- **target**: a player, a list of players or `"*"` (everyone). Commands to the game (`game.*`) only reach those playing in the server's game and return how many they reached.
- **item**, **actor**, **scene**: a game id or its name from [IDS.md](IDS.md) (`"MASK_BUNNY"`, `"EN_DODONGO"`, `"SOUTH_CLOCK_TOWN"`).
- **level**: `"info"` (if omitted), `"ok"`, `"warn"` or `"error"`: the color of the line in the chat.

### Functions that take functions

Each engine provides them: in a plugin they are methods of `coop::Plugin` (`On`, `Off`, `After`, `Every`, `CancelTimer`, `Command`; see [PLUGINS.md](PLUGINS.md)).

#### `coop.on(event, fn)`

Returns: number

Listens to an event: one from the list below or a custom one between mods (with `:` in the name). `fn(e)` receives the event table; in a cancelable one, `return false` (or `e.cancel = true`) cancels it, and assigning a writable field (`e.text = "..."`) changes it. Returns the subscription id. A name without `:` that is not in the list is an error (so a misspelled one does not go unnoticed).

#### `coop.off(id)`

Returns: boolean

Stops listening: the id that `coop.on` returned.

#### `coop.emit(name, payload?)`

Returns: table, boolean

Fires a custom event for other mods (the name contains `:`, like `"economy:payment"`) with the `payload` table. Returns the table as its handlers left it (they may change any field) and whether any of them cancelled it. Plugins can listen to these events, but only scripts fire them.

#### `coop.timer.after(ms, fn)`

Returns: number

Calls `fn()` once, `ms` milliseconds from now (at least 10; at most 30 days). Returns the timer id.

#### `coop.timer.every(ms, fn)`

Returns: number

Calls `fn()` every `ms` milliseconds (at least 10) until it is cancelled or the mod is unloaded. Returns its id.

#### `coop.timer.cancel(id)`

Returns: boolean

Cancels a timer of this mod.

#### `coop.commands.register(name, opts?, fn)`

Returns: nothing

Creates the command `/name`. `opts` = `{ usage = "/name <x>", help = "...", perm = "player" | "op" | "console", minArgs = 0, aliases = { "other" } }` (all optional; `perm` says who can use it and `commandPermissions` in `server.json` can change it). `fn(ctx, args)` receives who typed it (`ctx.player`, missing if it is the console; `ctx.nick`, `ctx.isConsole`, `ctx.isOp`) and its arguments (strings); what it returns is the reply: a text and, optionally, its level (`"ok"`, `"warn"`, `"error"`). `/help` shows it with its help. A name that already exists is an error.

#### `coop.commands.unregister(name)`

Returns: boolean

Removes a command of this mod.

### server

#### `coop.server.config(key)`

Returns: value

Reads an option of `server.json`: `port`, `language`, `maxPlayers`, `motd`, `sharedEnemies`, `sharedProps`, `endingForAll`, `groups`, `bossCutscenes`, `inviteSeconds`, `effects`, `timeSpeed`, `voteSeconds`, `saveSeconds`, `giftMax`, `commandPermissions`, `gameSettings`. The password cannot be read.

#### `coop.server.exec(line)`

Returns: text

Runs a command as if it were typed in the server console (with every permission), for example `coop.server.exec("kick Ana spam")`. Returns what the command answered.

#### `coop.server.info()`

Returns: table

Server data: `protocol` (protocol version), `language` (`es`, `en`, `zh`, `ru`), `port`, `maxPlayers`, `players` (connected now), `uptimeMs`, `timeSpeed` and `mods` (how many are loaded).

#### `coop.server.log(text, level?)`

Returns: nothing

Writes a line in the server log (console and `logs/server.log`) with the mod's name in front. `level`: `info` (default), `warn` or `error`.

#### `coop.server.now()`

Returns: number

Milliseconds since the server started. Useful to measure durations; it is not the time of day.

#### `coop.server.setConfig(key, value)`

Returns: nothing

Changes an option while the server is running (it is not saved to `server.json`): `motd`, `password`, `maxPlayers` (1-4), `inviteSeconds`, `bossCutscenes`, `effects`, `voteSeconds`, `saveSeconds`, `giftMax` and `timeSpeed`.

#### `coop.server.stop(reason?)`

Returns: nothing

Stops the server in an orderly way (warns the players and saves the world).

### players

#### `coop.players.ban(player, reason?)`

Returns: nothing

Bans the nick and IP of a connected player and kicks them (like `/ban`).

#### `coop.players.count()`

Returns: number

How many players are connected.

#### `coop.players.find(nick)`

Returns: number or nil

The id of the player with that nick (case-insensitive), or `nil`.

#### `coop.players.get(player)`

Returns: table or nil

A player's data (by id or nick), or `nil` if they are not connected: `id`, `nick`, `ip`, `op`, `scene`, `sceneKey`, `sceneName`, `room`, `entrance`, `x`, `y`, `z`, `rot`, `inWorld` (playing in the server's game), `busy` (in a cutscene), `group` (0: no group), `activity` (minigame key), `form` (0 Fierce Deity, 1 Goron, 2 Zora, 3 Deku, 4 human), `mask`, `connectedMs` and, once their game has reported them, `health`, `maxHealth`, `magic` and `rupees`.

#### `coop.players.inScene(scene)`

Returns: list

The ids of the players who are in that scene (its id or its name, such as `"SOUTH_CLOCK_TOWN"`).

#### `coop.players.inWorld()`

Returns: list

The ids of the players who are playing in the server's game.

#### `coop.players.isOp(player)`

Returns: boolean

Whether that player is an admin.

#### `coop.players.kick(player, reason?)`

Returns: nothing

Kicks a player from the server.

#### `coop.players.list()`

Returns: list

The ids of the connected players.

#### `coop.players.near(player, radius)`

Returns: list

The ids of the other players in the same scene who are within `radius` units (Link is about 60 tall).

#### `coop.players.setOp(player, op)`

Returns: nothing

Grants (`true`) or removes (`false`) admin permissions for a connected player. They are tied to their nick and to the IP they have now.

#### `coop.players.teleport(player, dest)`

Returns: nothing

Takes a player next to another one (`dest` = id or nick, like `/tp`) or to an exact point: `dest` = `{ scene = "SOUTH_CLOCK_TOWN", x = 0, y = 0, z = 0, room = 0, rot = 0 }` (`scene` by name or id; `entrance` also works instead). If Link is in a dialogue or a cutscene, their game does not move them.

### chat

#### `coop.chat.broadcast(text, level?)`

Returns: nothing

Writes a system line in the chat of every connected player (and in the log). `level` gives it a color: `info` (default), `ok`, `warn` or `error`. The text may have up to 8 lines separated by `\n`.

#### `coop.chat.say(name, text)`

Returns: nothing

Writes a normal line in everyone's chat, as if `name` (a character, a bot) said it: `<Tatl> Listen!`. `name` does not have to be a player.

#### `coop.chat.tell(player, text, level?)`

Returns: nothing

Writes a system line only in that player's chat.

### world

#### `coop.world.add(field, offset, delta)`

Returns: number

Adds `delta` (may be negative) to a counter (`heartQuarters`, `keys`, `fairies`, `skulls`, `bottles`). Returns how much was actually added (the counter does not leave its range).

#### `coop.world.crashMoon()`

Returns: nothing

The moon falls now: the world goes back to the start of the cycle, as if nobody had played the Song of Time.

#### `coop.world.cycle()`

Returns: number

The number of the current three-day cycle (1 the first; 0 if there is no world yet).

#### `coop.world.exists()`

Returns: boolean

Whether the server's world already exists (the first player to enter the game creates it).

#### `coop.world.fields()`

Returns: list

The fields of the shared world: `{ name, size (bytes), kind }`, with `kind` = `bits` (flags), `bytes` (values) or `counter` (counters).

#### `coop.world.get(field, offset)`

Returns: number

Reads a byte of a world field (by name or index); in a `counter` field, the counter that starts at that byte.

#### `coop.world.getBit(field, offset, mask)`

Returns: boolean

Whether all the bits of `mask` are set in that byte. Example: `coop.world.getBit("owls", 0, 0x01)`.

#### `coop.world.restart()`

Returns: nothing

Goes back to Dawn of the First Day without a vote (like `/reiniciar`): each player keeps what the Song of Time keeps.

#### `coop.world.set(field, offset, value)`

Returns: boolean

Writes a byte of a `bytes` field (for example a mask in `masks`) or sets a counter, for all players. Returns whether anything changed.

#### `coop.world.setBits(field, offset, set, clear?)`

Returns: boolean

Sets the bits of `set` and clears those of `clear` in a byte of a `bits` field (quest flags, chests, owls...), for all players. Returns whether anything changed.

#### `coop.world.setSpeed(speed)`

Returns: nothing

Changes the speed at which the three days pass: 1 is the original game's, 0.5 half (days twice as long), 2 double. Between 0.1 and 10.

#### `coop.world.setStopped(stopped)`

Returns: nothing

Stops (`true`) or resumes (`false`) the world clock, like `/freezetime`. It stays that way even as players come and go.

#### `coop.world.setTime(day, hour, minute?)`

Returns: nothing

Jumps everyone to that moment (day 1-3, hour 0-23). The games reload their scene, as with `/settime`.

#### `coop.world.time()`

Returns: table or nil

The world clock: `day` (1-3), `hour`, `minute`, `night`, `stopped`, `inverted` (Inverted Song of Time), `speed` (time speed), `abs` (units since day 1 at 6:00; one day is 65536) and `time` (the time as the game stores it). `nil` if there is no world.

### game

#### `coop.game.clearSetting(target, name)`

Returns: nothing

Stops forcing that option: everyone's with `"*"`, or those players' own.

#### `coop.game.damage(target, amount)`

Returns: number

Takes `amount` of health (16 = one heart; double defense halves it), without knockback. If they run out of health, Link dies as in the game (a bottled fairy revives him).

#### `coop.game.giveItem(target, item)`

Returns: number

Gives an item (by name, such as `"MASK_BUNNY"`, or by id) the way the game does but without the chest animation: items, masks, bottle contents (they fill an empty one), equipment, ammo, upgrades, songs, hearts and rupees. The few ids the game cannot give (`SWORD_DEITY`, `WALLET_DEFAULT`, `FISHING_ROD`, `STRAY_FAIRIES`, `INVALID_*`) raise an error. The names are in `IDS.md`.

#### `coop.game.giveRupees(target, amount)`

Returns: number

Gives rupees, or takes them with a negative number (-9999 to 9999). What does not fit in the wallet is lost.

#### `coop.game.heal(target, amount?)`

Returns: number

Heals `amount` of health (16 = one heart). Without `amount`, or with 0, heals fully.

#### `coop.game.idOf(kind, name)`

Returns: number or nil

The id of a name, or `nil` if the game has nothing with that name. Case-insensitive, and it accepts the game prefix (`ITEM_`, `ACTOR_`, `SCENE_`).

#### `coop.game.ids(kind)`

Returns: table

All the names of a kind (`"item"`, `"actor"` or `"scene"`) with their id: `{ MASK_BUNNY = 57, ... }`.

#### `coop.game.kill(target)`

Returns: number

Takes all the health of those players.

#### `coop.game.magic(target, amount?)`

Returns: number

Gives magic, or takes it with a negative number (48 is the normal bar, 96 the double one). Without `amount`, or with 0, fills it.

#### `coop.game.message(target, text)`

Returns: number

Opens a game text box with that message, like a sign's (line breaks allowed; a new box every 4 lines). The game's font has no accents: they are removed (`á` → `a`, `ñ` → `n`, no `¡ ¿`); `%r` `%g` `%b` `%y` `%p` `%w` change the color (red, green, blue, yellow, pink, white). If Link is busy (another dialogue, a cutscene, the menu, on horseback), it waits up to 10 seconds for him to be free; otherwise the message reaches them as a chat line.

#### `coop.game.nameOf(kind, id)`

Returns: text or nil

The name of an id, or `nil` if it does not exist.

#### `coop.game.notify(target, text, seconds?)`

Returns: number

Shows a pop-up notice (2 Ship's notification, in a corner of the screen) for `seconds` seconds (1 to 30; 6 if omitted). The text is cut to 400 characters.

#### `coop.game.setSetting(target, name, value)`

Returns: nothing

Forces a 2 Ship option (a game CVar: `gEnhancements.*`, `gCheats.*`, `gModes.*`, `gFixes.*`) while playing in the server's game; on leaving, each game gets its own back. With `target` = `"*"` it applies to everyone, also to whoever enters later; with a player or a list, only to them and until they disconnect. `value`: an integer for integer options (checkboxes: 1 or 0; lists), one with decimals for sliders (`2.0`, not `2`); `true` and `false` count as 1 and 0. At most 64 options per player.

#### `coop.game.settings(player?)`

Returns: table

The forced options, `{ name = value }`: without arguments, everyone's (including those from `gameSettings` in `server.json`); with a player, all the ones they have.

#### `coop.game.sound(target, sfx)`

Returns: number

Plays a game sound effect by its id (the game's `NA_SE_*`, from 0 to 65535; for example `0x4802` is the success jingle, `0x4803` a rupee and `0x4806` the error one).

#### `coop.game.spawn(target, actor, opts?)`

Returns: number

Creates an actor (by name, such as `"EN_DODONGO"`, or by id) in those players' games. `opts` = `{ params = 0, distance = 100, rotY = 0, x = ..., y = ..., z = ... }`: without `x, y, z` it appears `distance` units in front of Link (0 to 2000). Each game creates its own: it is not shared with the other players. It is created even if the scene does not use that actor, but an enemy does not appear in a room that is already cleared and some actors only work in their own scene (bosses, mechanisms).

#### `coop.game.takeItem(target, item)`

Returns: number

Takes an item from the items or masks screen if they have it (a bottle content takes its bottle with it). With the rest (equipment, songs, ammo) it does nothing, and it never takes the mask Link is wearing nor the one of his form.

#### `coop.game.unlockAll(target)`

Returns: number

Gives those players every item, mask, song and heart (what `/unlockall` does).

#### `coop.game.warp(target, scene, spawn?)`

Returns: number

Takes those players to a scene (by name, such as `"SOUTH_CLOCK_TOWN"`, or by id) through its entrance number `spawn` (0 to 31; 0 if omitted). If Link is in a dialogue or a cutscene, it waits up to 10 seconds.

### storage

#### `coop.storage.get(key, default?)`

Returns: value

What this mod saved under that key, or `default` if there is nothing. Each mod's data is its own: another mod does not see it.

#### `coop.storage.keys()`

Returns: list

The keys this mod has saved, in alphabetical order.

#### `coop.storage.remove(key)`

Returns: boolean

Deletes a key. Returns whether it existed.

#### `coop.storage.save()`

Returns: nothing

Writes the data to disk right now (normally not needed).

#### `coop.storage.set(key, value)`

Returns: nothing

Saves a value (number, text, boolean or table) that will still be there when the server restarts. `nil` deletes it. It is written to `<dataDir>/<mod>.json` at most every 2 seconds and on stop.

### mod

#### `coop.mod.describe(info)`

Returns: nothing

Says what this mod is, for the `/mods` command: `{ title = "...", version = "1.0", author = "...", description = "..." }` (all optional).

#### `coop.mod.list()`

Returns: list

The loaded mods, in load order: `{ name, kind ("lua" or "plugin"), title, version, author, description }`.

#### `coop.mod.name()`

Returns: text

This mod's name: its file name, in lowercase and without extension (`mods/My Mod.lua` is `my_mod`).

#### `coop.mod.setting(key, default?)`

Returns: value

A setting of this mod written by the server owner in `server.json`, under `mods.settings.<mod name>`. If it is not there, returns `default`.

## Events

A script listens to an event with `coop.on("name", function(e) ... end)` and a plugin with `api.On("name", ...)`. The handler receives the event's fields (`e.nick`, `e.player`...); `player` is the player's id and is valid for the functions as long as they stay connected. In cancelable events, `return false` (or `e.cancel = true`) prevents what they announce, and writable fields are changed by assigning them. Handlers are called in the order they subscribed; if one cancels, the following ones do not receive it.

### `server_start`

The server has started and the configured mods are loaded.

No fields.

### `server_stop`

The server is about to stop.

| Field | Type | Writable | What it is |
|---|---|---|---|
| `reason` | string |  | Why it is stopping |

### `player_connect` (cancelable)

A player has passed the server's checks (version, nick, bans, password) and is about to enter. Cancelling it rejects them with `reason`.

| Field | Type | Writable | What it is |
|---|---|---|---|
| `nick` | string |  | Nick they enter with |
| `ip` | string |  | Their IP address |
| `reason` | string | yes | Reason they will see if it is cancelled |

### `player_join`

A player has entered the server.

| Field | Type | Writable | What it is |
|---|---|---|---|
| `player` | int |  | Player id |
| `nick` | string |  | Their nick |
| `ip` | string |  | Their IP address |

### `player_leave`

A player has disconnected. Their id is still valid inside the handler.

| Field | Type | Writable | What it is |
|---|---|---|---|
| `player` | int |  | Player id |
| `nick` | string |  | Their nick |
| `reason` | string |  | Reason (disconnected, kicked...) |

### `player_scene`

A player has changed scene or room.

| Field | Type | Writable | What it is |
|---|---|---|---|
| `player` | int |  | Player id |
| `nick` | string |  | Their nick |
| `scene` | int |  | Scene id |
| `sceneKey` | string |  | Scene key (`SOUTH_CLOCK_TOWN`...; empty if unknown) |

### `player_stats`

A player's health, magic or rupees have changed (at most 4 notices per second and player).

| `prevHealth` | int |  | Previous health |
| `prevMagic` | int |  | Previous magic |
| `prevRupees` | int |  | Previous rupees |

| Field | Type | Writable | What it is |

### `mod_unload`

This mod is about to be unloaded (only it receives this).

No fields.
